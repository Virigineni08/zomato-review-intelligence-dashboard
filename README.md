# 🍽️ Zomato Review Intelligence Dashboard

## 📌 Project Overview

The Zomato Review Intelligence Dashboard is a Machine Learning and NLP-based web application that analyzes restaurant reviews, predicts customer sentiment, and provides business insights through interactive dashboards.

---

## 🚀 Features

* 😊 Sentiment Analysis using Multinomial Naive Bayes
* 🧠 TF-IDF Text Vectorization
* 📊 Restaurant Clustering using K-Means
* 📈 Analytics Dashboard
* 🔍 Restaurant Search
* 📥 Download Prediction History
* 📋 Recent Prediction History
* 🎨 Interactive Streamlit UI

---

## 🛠 Technologies Used

* Python
* Streamlit
* Scikit-learn
* Pandas
* NumPy
* Plotly
* Pickle

## ▶️ Run Locally

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
